## 2. Phase-by-Phase Audit & Verification Evidence

### Phase 1: Strict Web3 Data Models (`CORE-01` to `CORE-05`)
- **Artifacts:** `backend/core/models.py`, `backend/tests/test_core_models.py`
- **Verification:** 7 tests passing.
- **Key Evidence:**
  - `IntentEnvelope` enforces per-asset budget dictionaries (`max_single_value_per_asset` and `max_session_value_per_asset`) rather than scalar thresholds.
  - `TransactionProposal` captures raw `to_address`, `value`, `data_hex`, `chain_id`, `nonce`, and generates deterministic SHA-256 proposal hash.
  - `DecodedEvmTransaction` models parsed fields (`recipient`, `amount`, `asset`, `method`, `contract_address`, `calldata_hash`).
  - `TrajectoryState` accumulates spend per distinct asset contract.
  - `DecisionReceipt` enforces BLOCK vs HOLD separation (`hold_reason` on uncertainty vs `violated_invariants` on policy breach).

### Phase 2: Deterministic EVM Calldata Decoder (`DEC-01` to `DEC-04`)
- **Artifacts:** `backend/chain/decoder.py`, `backend/tests/test_decoder.py`
- **Verification:** 11 tests passing.
- **Key Evidence:**
  - Pure Python parser for native ETH transfers and ERC-20 `transfer(address,uint256)` (`0xa9059cbb`).
  - Zero LLM calls, zero network RPC requests.
  - Strict fail-closed semantics: truncated selectors, odd hex lengths, malformed addresses, and unexpected exceptions catch safely and return `DecodeResult(parseable=False, hold_reason=...)`.

## 5. Security & Product Hardening Review

Four critical product hardening locks were established and verified:
1. **Deterministic BLOCK vs HOLD Separation:**
   - `BLOCK`: Triggered by known invariant violations (e.g. wrong recipient, budget breach). Identifies specific invariant name.
   - `HOLD`: Triggered by unprovable states (malformed hex, truncated calldata, unknown selector). Identifies specific `hold_reason`.
   - **Crucial Invariant:** Neither state permits signing or broadcast.
2. **Per-Asset Budget Limits:**
   - Intent envelopes declare maps (e.g. `{"USDC": 50, "ETH": 0}`), preventing multi-asset evasion.
3. **Calldata as Sole Authority:**
   - Decoded from actual bytes and `tx.value`, completely eliminating tool-name spoofing.
4. **Honest Execution Substrate Labeling:**
   - Local runs explicitly label `SIMULATED_LOCAL`; only the explicit testnet path claims `REAL_TESTNET`.
